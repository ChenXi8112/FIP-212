## 研讨课一：树的建模与遍历

1. **代码**：公司组织架构树的建模代码，以及前序、中序、后序三种递归遍历代码。
2. **手绘树照片**：组内手绘的公司组织架构树。
3. **一个遍历口诀**：用一句话概括三种遍历的访问顺序。

## 研讨课二：BST 项目

1. **项目代码（二选一）**：项目 A 为 BST 构建与查找；项目 B 为 BST 删除。
2. **手绘 BST 过程图**：项目 A 提交前 3 次插入及最终树；项目 B 提交依次删除 20、30、50 后的树形图（各一步一张）。
3. **查找策略反思（1 句话）**：说明本次任务中 BST 相对排序数组的优势。
