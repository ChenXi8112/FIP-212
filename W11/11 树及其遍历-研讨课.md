## 研讨课二 · 加练：AI 的 BST 删除

**读错码**（AI 常把“两子结点”情况写错）：

```python
def delete(root, val):
    if not root:
        return None
    if val < root.val:
        root.left = delete(root.left, val)
    elif val > root.val:
        root.right = delete(root.right, val)
    else:
        if not root.left:
            return root.right
        if not root.right:
            return root.left
        # 两个子结点：直接用左子树替代
        return root.left
    return root
```

**讨论**：删除根 `10`（左右都有孩子）时，BST 性质还成立吗？应如何改？（提示：后继结点）

---

## 关键认识

- BST 查找 = 二分查找的树形版
- 平均 O(log n)，最坏 O(n)（有序插入退化）
- 数据不变 → 排序数组；数据常变 → BST
- 中序遍历 BST 一定有序
