## 任务单

同一组 `temps`、目标 `29.5`（见 W4 研讨课教案 / 本周课件）。

### 任务 1：哈希查找

```python
temp_dict = {}
for i, t in enumerate(temps):
    temp_dict[t] = i
idx = temp_dict[29.5]   # 原表下标 5，不是排序后的 22
```

思考：构建 O(n)；查 100 次总代价？重复键怎么办？

### 三策略对比表

| 策略 | 前提 | 本次 | 构建 | 适用 |
|:---|:---|:---|:---|:---|
| 线性 | 无序 | **6** | 无 | 只查一次 |
| 二分 | 有序 | **2** | 排序 | 连查 |
| 哈希 | 键值 | **1**（定位） | O(n) 建表 | 按键反复查 |

### 盈亏直觉

查 k 次：线性约 k·n；哈希约 n+k。只查一次，哈希未必更省（建表也要扫一遍）。

## 文件伏笔（约 12 分）

讲座词频用的是内存字符串。把 `demo/fox.txt` 复制到 `w5_lab/`（或 `cd` 到 `demo/`），用**文件**再跑一遍：

```python
count = {}
f = open('fox.txt')
for line in f:
    for word in line.split():
        count[word] = count.get(word, 0) + 1
f.close()
print(count)
```

助教巡视三点：

| 检查 | 通过标准 |
|:---|:---|
| 当前目录 | 能找到 `fox.txt`，否则 `FileNotFoundError`（还 W1 路径的账） |
| 遍历 | `for line in f` 后还要对 `line.split()`，不是 `f.split()` |
| 关闭 | 循环结束后有 `close()` |

口头点到为止：**有一种写法能保证关文件，包括中途出错——W15 揭晓。** 本周不要引入 `with` / `encoding`。本周文件是英文，避开 Windows 默认编码。

讲座已立名异常：若出现 `FileNotFoundError`，先读最后一行类型，**不要** `except: pass` 吞掉——改当前目录。缺键词频仍用 `get`，不靠 `try/except`。

预期输出：`the` 2 次，`fox` 2 次，其余 1 次。
