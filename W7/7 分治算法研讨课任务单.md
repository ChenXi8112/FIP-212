### 主任务：简洁版快速排序（必做，20分钟）

**问题**：实现快速排序，选取第一个元素为基准，将列表分为"小于基准"和"大于等于基准"两部分，递归排序。

**代码框架**：
```python
def quick_sort(arr):
    if len(arr) <= 1:        # Base Case
        return arr
    pivot = arr[0]           # 选取基准（第一个元素）
    left = [x for x in arr[1:] if x < pivot]     # 小于基准
    right = [x for x in arr[1:] if x >= pivot]   # 大于等于基准
    return quick_sort(left) + [pivot] + quick_sort(right)
```

**测试**：
```python
print(quick_sort([3, 1, 4, 1, 5, 9, 2, 6]))
# 预期: [1, 1, 2, 3, 4, 5, 6, 9]
```

### 变式1：测试已排序列表（必做，10分钟）

**问题**：用 `[1, 2, 3, 4, 5, 6, 7, 8]` 测试你的快排，观察递归深度。

**思考**：
- 基准值总是第一个元素（最小值），分区后 `left` 为空，`right` 有 n-1 个元素。
- 递归深度是多少？（提示：n 层，不是 log n）
- 这对应什么复杂度？（提示：O(n²)）

**解决方案**：随机化基准值。
```python
import random
pivot = random.choice(arr)  # 随机选基准，避免最坏情况
```

### 变式2：手工分区游戏（10分钟）

**规则**：给定列表 `[8, 3, 5, 1, 7, 2, 9, 4]`，选择基准值 `5`，在纸上手工完成分区：

1. 遍历每个元素，判断 `< 5` 还是 `>= 5`
2. 写出 `left` 列表和 `right` 列表
3. 验证：`left` 的所有元素 `< 5`，`right` 的所有元素 `>= 5`
4. 基准值 `5` 的最终位置在哪里？

**思考**：分区完成后，基准值 `5` 是否已经在它"最终排序的位置"上了？（是的！这是快排与归并排序的关键差异。）

### 变式3（弹性）：三路分区

如果列表中有大量重复元素（如 `[3, 1, 4, 1, 5, 9, 2, 6, 1, 1, 1]`），简洁版快排会将所有等于基准的元素放到 `right`，导致 `right` 很长。

**改进**：将列表分为三路——`小于`、`等于`、`大于`。

```python
def quick_sort_3way(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    less = [x for x in arr if x < pivot]
    equal = [x for x in arr if x == pivot]
    greater = [x for x in arr if x > pivot]
    return quick_sort_3way(less) + equal + quick_sort_3way(greater)
```

**思考**：三路分区在处理重复元素时有什么优势？（提示：`equal` 部分不需要再递归排序）
