## 1.退化测试记录  
**初始输入：**`[1,2,3,4,5,6,7,8]`  
|递归深度|最长子列表|最长子列表长度|
|:---:|:---|:---:|
|1|`[2,3,4,5,6,7,8]`|7|  
|2|`[3,4,5,6,7,8]`|6| 
|3|`[4,5,6,7,8]`|5|
|4|`[5,6,7,8]`|4|  
|5|`[6,7,8]`|3| 
|6|`[7,8]`|2| 
|7|`[8]`|1| 

**最大递归层数：** 8  
**退化原因：** 每次哨兵固定选为`arr[0]`，导致在列表本身有序时，左列表总为空，右列表长度只减少1，时间复杂度由理论上的$O(n \log n)$退化为$O(n^2)$

## 3.一个快排的坑  
**终端输出（现象）：**```
 IndexError: list index out of range ```
**原因：** 判断是否直接`return`的代码为
```
if len(arr) == 1:
  return arr
```
这忽略了`arr`为空列表的情况，导致后续确认“哨兵”时调用`arr[0]`导致异常  
**修正方式：** 把等于的判断换成小于等于即可
