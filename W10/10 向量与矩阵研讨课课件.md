# 余弦 vs 欧氏：怎么选？

| 度量 | 公式 | 看的是什么 | 受尺度影响？ |
|:---|:---|:---|:---|
| **余弦相似度** | $\dfrac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$ | 方向是否一致 | **否** |
| **欧几里得距离** | $\|\mathbf{u}-\mathbf{v}\|_2$ | 两点直线距离 | **是** |

**直觉**：
- 评分尺度不同、比“口味是否像”→ **余弦**
- 关心绝对差距、在同一尺度下比远近 → **欧氏**

# NumPy 向量运算速查

| 运算 | 写法 | 注意 |
|:---|:---|:---|
| 内积 | `np.dot(u, v)` | 两向量长度相同 |
| L2 范数 | `np.linalg.norm(v)` | $\sqrt{\sum v_i^2}$，不是 `sum(v)` |
| 差向量 | `u - v` | 欧氏距离的基础 |
| 欧氏距离 | `np.linalg.norm(u - v)` | 不是 `abs(u-v).sum()`（那是 L1） |
| 逐元素运算 | `u + v`, `u * 2` | `*` 是逐元素，不是矩阵乘 |

**余弦相似度模板**：

```python
def cosine_similarity(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
```

# 任务 1：用户相似度（必做，约 8 分钟）

**数据**：5 用户对 4 类电影的评分

```python
import numpy as np

users = {
    "Alice":  np.array([5, 1, 2, 4]),
    "Bob":    np.array([4, 2, 1, 5]),
    "Carol":  np.array([1, 5, 5, 1]),
    "Dave":   np.array([5, 1, 2, 4]),
    "Eve":    np.array([3, 3, 3, 3]),
}
```

**任务**：
1. 实现 `cosine_similarity`、`euclidean_distance`
2. 算 Alice 与其他 4 人的余弦相似度与欧氏距离
3. 谁和 Alice 最相似？两种度量结论一致吗？

---

# 任务 1：代码框架

```python
def cosine_similarity(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))

def euclidean_distance(u, v):
    return np.linalg.norm(u - v)

for name, vec in users.items():
    if name != "Alice":
        cos = cosine_similarity(users["Alice"], vec)
        dist = euclidean_distance(users["Alice"], vec)
        print(f"{name}: cos={cos:.3f}, dist={dist:.3f}")
```

# 任务 1：参考答案

| 用户 | cos（与 Alice） | dist（与 Alice） | 说明 |
|:---|:---|:---|:---|

| Bob | 0.887 | 2.236 | 方向较接近 |
| Eve | 0.728 | 3.464 | 各维均衡 |
| Carol | 0.357 | 7.071 | 偏好相反 |

**思考**：Dave 余弦 = 1 但能否说“品味完全相同”？（方向相同、可差一个正数倍；此处向量相等）

# 任务 2：代码片段

```python
carol = users["Carol"]
best_name, best_cos = None, -1
for name, vec in users.items():
    if name == "Carol":
        continue
    cos = cosine_similarity(carol, vec)
    if cos > best_cos:
        best_cos, best_name = cos, name

print(f"与 Carol 最相似: {best_name}, cos={best_cos:.3f}")
favorite_genre = np.argmax(users[best_name])
print(f"该用户最喜欢第 {favorite_genre} 类")
```

**参考**：最相似常为 Eve（各维均衡，cos 较高）；数据量小，推荐效果有限——体会流程即可。

# 研讨课一收束：典型错误

| 典型错误 | 现象 | 修正 |
|:---|:---|:---|
| 余弦忘记除范数 | 结果 > 1 | 必须除以 $\|\mathbf{u}\|\|\mathbf{v}\|$ |
| 把 `norm` 当 `sum` | 数值偏大 | $\sqrt{\sum v_i^2}$ |
| 欧氏用 `abs(u-v).sum()` | 曼哈顿距离 | 用 `np.linalg.norm(u-v)` |
| 推荐不检查已观看 | 逻辑漏洞 | 过滤用户已有条目 |

3. **复合**：先旋转再缩放 → `(S @ R) @ points.T`

[RotationMatrix.py](../../2%20课件/10%20向量与矩阵/demo/RotationMatrix.py) — 向量旋转动画

# 项目 A：代码框架

```python
S = np.array([[2, 0], [0, 2]])
R = np.array([[0, -1], [1, 0]])

# (2,2) @ (2,4)：点矩阵需 (2, N)，故 points.T
transformed = (S @ R) @ points.T
print(transformed.T)   # 转回 (N, 2)，每行一个点
```

**形状追踪**：

| 对象 | shape |
|:---|:---|
| `points` | $(4, 2)$ |
| `points.T` | $(2, 4)$ |
| `S @ R` | $(2, 2)$ |
| 结果 | $(2, 4)$ → `.T` → $(4, 2)$ |

---

# 项目 A：思考题

1. **为何转置？** 变换矩阵 $(2,2)$ 应左乘 $(2, N)$ 的点矩阵；`points` 是 $(N,2)$。

2. **`S @ R` vs `R @ S` 一样吗？** 不一样。矩阵从**右向左**作用：`S @ R @ v` 先 $R$ 后 $S$。

3. **绕非原点旋转？** 需平移 → 旋转 → 平移回去；平移要用 $3\times3$ **齐次坐标**（拓展）。

# 项目 B：批量相似度矩阵

```python
np.random.seed(42)
ratings = np.random.randint(1, 6, size=(10, 5))   # 10 用户 × 5 电影
```

**任务**：
1. **按行归一化**（每个用户向量范数 → 1）
2. `sim_matrix = normalized @ normalized.T`
3. 为用户 0 找最相似的其他用户（**排除自己**）
4. 用 `cosine_similarity(ratings[0], ratings[j])` 手动验证

---

# 项目 B：代码框架

```python
norms = np.linalg.norm(ratings, axis=1, keepdims=True)  # (10, 1)
normalized = ratings / norms                                # 广播

sim_matrix = normalized @ normalized.T   # (10, 5) @ (5, 10) → (10, 10)
# sim_matrix[i, j] = 用户 i 与 j 的余弦相似度

sim_0 = sim_matrix[0].copy()
sim_0[0] = -1                    # 排除自己
best = np.argmax(sim_0)
print(f"与用户 0 最相似: 用户 {best}, sim={sim_0[best]:.3f}")
```

**关键**：未归一化时 `ratings @ ratings.T` 是**内积矩阵**，不是余弦相似度。

---

# 项目 B：思考题

1. 为何归一化后内积 = 余弦？（单位向量内积 = $\cos\theta$）

2. `axis=1` 还是 `axis=0`？每个用户是**一行** → 对行求范数 → `axis=1`；`keepdims=True` 便于广播。

3. 与双重循环比？复杂度同为 $O(n^2 m)$ 量级，但 `@` 底层 C/BLAS 优化，**实际快得多**。

# 研讨课二收束：典型错误

| 典型错误 | 现象 | 修正 |
|:---|:---|:---|
| 忘记 `points.T` | 维度不匹配 | $(2,2)@(2,N)$，点需 $(2,N)$ |
| 变换顺序搞反 | 几何结果错 | `S@R@v`：先 $R$ 后 $S$ |
| 相似度矩阵未排除自己 | 最相似是自己 | 对角线恒为 1，置 `-1` 再 `argmax` |
| 归一化 `axis=0` | 按列归一化 | 每用户一行 → `axis=1` |

# 矩阵思维反思

1. 图像变换：不用矩阵，逐个 `for` 变换 $N$ 个点要多少行？用矩阵呢？

2. 批量相似度：`normalized @ normalized.T` **一行**替代了什么？（$n\times n$ 次函数调用）

3. **关键认识**：矩阵思维不是“把循环写短”，而是用更高层数学描述计算——一行公式可等价数十行循环，且底层更快。
