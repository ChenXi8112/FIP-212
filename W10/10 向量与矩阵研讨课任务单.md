### 任务 1：用户相似度计算（必做，8 分钟）

**数据**：5 个用户对 4 种电影类型的评分

```python
import numpy as np

users = {
    "Alice":  np.array([5, 1, 2, 4]),
    "Bob":    np.array([4, 2, 1, 5]),
    "Carol":  np.array([1, 5, 5, 1]),
    "Dave":   np.array([5, 1, 2, 4]),
    "Eve":    np.array([3, 3, 3, 3])
}
```

**任务**：
1. 用公式实现 `cosine_similarity(u, v)` 函数（用 `np.dot` 和 `np.linalg.norm`）。
2. 计算 Alice 与其他 4 人的余弦相似度。
3. 计算 Alice 与其他 4 人的欧几里得距离。
4. 对比两种度量：谁和 Alice 最相似？两种度量结论一致吗？

**代码框架**：
```python
def cosine_similarity(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))

def euclidean_distance(u, v):
    return np.linalg.norm(u - v)

# 计算并打印结果
for name, vec in users.items():
    if name != "Alice":
        cos = cosine_similarity(users["Alice"], vec)
        dist = euclidean_distance(users["Alice"], vec)
        print(f"{name}: cos={cos:.3f}, dist={dist:.3f}")
```

## 项目 A：图像几何变换（二选一）

### 背景

一张数字图像由像素点组成，每个像素是一个坐标点 `(x, y)`。用矩阵乘法可以对所有像素同时进行几何变换。

### 数据

```python
import numpy as np

# 一个简单图形的 4 个顶点（矩形）
points = np.array([
    [0, 0],   # 左下
    [2, 0],   # 右下
    [2, 1],   # 右上
    [0, 1]    # 左上
])  # 形状 (4, 2)，每行是一个点 (x, y)
```

### 任务

1. **缩放**：用矩阵 `S = [[2, 0], [0, 3]]` 对矩形进行缩放，观察新坐标。
2. **旋转 90 度**：用矩阵 `R = [[0, -1], [1, 0]]` 对矩形进行旋转，观察新坐标。
3. **复合变换**：先旋转 90 度，再缩放 `(2, 2)`。计算 `S @ R @ points.T`（注意转置）。
4. **验证**：手工计算第一个点 `[0, 0]` 和第二个点 `[2, 0]` 变换后的位置，与程序结果对比。

### 代码框架

```python
# 注意：points 形状是 (4, 2)，矩阵乘法要求 (2, 2) @ (2, 4)
# 所以需要转置：points.T 形状 (2, 4)
S = np.array([[2, 0], [0, 2]])
R = np.array([[0, -1], [1, 0]])

# 复合变换：先旋转，再缩放
# 矩阵从右向左作用：S @ R 表示"先 R 后 S"
transformed = (S @ R) @ points.T
print("变换后坐标（转置前）:")
print(transformed)
print("变换后坐标（转置后，每行一个点）:")
print(transformed.T)
```

### 思考

1. 为什么 `points` 需要转置？（提示：矩阵乘法要求 `(m,n) @ (n,p)`。变换矩阵是 `(2,2)`，点矩阵需要是 `(2, 4)`）
2. `S @ R` 和 `R @ S` 的结果一样吗？几何上分别代表什么？（提示：矩阵乘法不满足交换律。`S @ R` 是先旋转后缩放；`R @ S` 是先缩放后旋转）
3. 如果要实现"绕点 `(1, 0.5)` 旋转"（而非绕原点），需要怎么做？（提示：先平移使旋转中心到原点，旋转，再平移回去。平移不能用 2×2 矩阵实现，需要 3×3 齐次坐标——拓展思考）

## 项目 B：批量相似度计算（二选一）

### 背景

讲座课上我们逐个计算用户相似度。但如果用户量很大（如 1000 人），双重循环效率极低。利用矩阵乘法可以一次性计算所有用户两两之间的相似度。

### 数据

```python
import numpy as np

# 10 个用户，每个用户对 5 部电影的评分
np.random.seed(42)
ratings = np.random.randint(1, 6, size=(10, 5))  # 形状 (10, 5)
```

### 任务

1. **归一化**：对每个用户的评分向量，除以其范数，使其成为单位向量（范数为 1）。
   ```python
   norms = np.linalg.norm(ratings, axis=1, keepdims=True)  # 形状 (10, 1)
   normalized = ratings / norms                             # 广播：(10,5) / (10,1)
   ```

2. **相似度矩阵**：归一化后，用户 `i` 和用户 `j` 的余弦相似度等于 `normalized[i]` 与 `normalized[j]` 的内积。因此，所有用户两两相似度可以一次性计算：
   ```python
   sim_matrix = normalized @ normalized.T   # (10, 5) @ (5, 10) = (10, 10)
   ```
   `sim_matrix[i, j]` 就是用户 `i` 和用户 `j` 的余弦相似度。

3. **找最相似**：对第 0 个用户，找出与其最相似的其他用户（排除自己）。
   ```python
   sim_0 = sim_matrix[0].copy()
   sim_0[0] = -1   # 排除自己
   most_similar = np.argmax(sim_0)
   print(f"和用户 0 最相似的是用户 {most_similar}，相似度 {sim_0[most_similar]:.3f}")
   ```

4. **验证**：用 `cosine_similarity(ratings[0], ratings[most_similar])` 手动验证结果是否一致。

### 思考

1. `normalized @ normalized.T` 为什么能计算所有两两相似度？（提示：结果矩阵的 `(i,j)` 元素是 `normalized[i]` 和 `normalized[j]` 的内积。由于已归一化，内积 = 余弦相似度）
2. 如果没有先归一化，`ratings @ ratings.T` 的结果是什么？（提示：是内积矩阵，不是相似度矩阵。内积受范数影响）
3. 这个方法的计算复杂度是多少？对比双重循环逐个计算。（提示：矩阵乘法的复杂度是 O(n²×m)，其中 n 是用户数，m 是特征数。双重循环也是 O(n²×m)，但矩阵乘法在底层用 C 优化，实际快得多）
