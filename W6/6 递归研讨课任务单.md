## 任务单（每组1份）

### 背景

杨辉三角第 $n$ 行（从 0 计）是一个列表：两端为 1，中间等于**上一行**相邻两项之和。

```
        1          ← pascal(0) → [1]
      1   1        ← pascal(1) → [1, 1]
    1   2   1      ← pascal(2) → [1, 2, 1]
  1   3   3   1    ← pascal(3) → [1, 3, 3, 1]
1   4   6   4   1  ← pascal(4) → [1, 4, 6, 4, 1]
```

### 主任务：递归生成整行（必做，15分钟）

**问题**：编写 `pascal(n)`，返回第 $n$ 行整个列表。

**示例**：`pascal(4)` → `[1, 4, 6, 4, 1]`

**好写法**（上一行只算一次）：
```python
def pascal(n):
    if n == 0:
        return [1]
    prev = pascal(n - 1)
    row = [1]
    for i in range(len(prev) - 1):
        row.append(prev[i] + prev[i + 1])
    row.append(1)
    return row
```

**手工推演**：写出 `pascal(0)` 到 `pascal(3)` 各行。

### 变式1：找出坏写法（必做，10分钟）

若循环里写 `pascal(n-1)[i] + pascal(n-1)[i+1]`，上一行会被算多少次？

对比 `pascal_bad(16)` 与 `pascal(16)` 的耗时。

### 变式2：迭代实现（弹性，时间够时挑战）

从 `[1]` 出发，循环 $n$ 次拼出下一行，返回整行（不要只返回某一个格子）。

**思考**：迭代和「好」递归是不是同一递推、方向相反？

## `@` 怎么用（助教讲约 2 分钟，Cursor 为例）

- 在对话里输入 `@`，选中当前工作区里的 `pascal.py` 或文件夹 `w6_lab`。
- `@` 是**这一轮对话的临时上下文**：AI 能读到文件，提示词里仍要写清 Base Case 等约束——`@` 不能代替规格。
- 其他工具类比：VS Code Copilot 常用 `#file`；不会 `@` 的，至少打开工作区再问，不要从网页对话框空手开写。
- **不讲** `@web` / `@git` / `@docs` 等全家桶，本周只要“把我的 `.py` 给 AI 看”。

**巡视**：发现整份代码粘进对话框 → 打断，改成 `@pascal.py` 再问“上一行算了几次”。
