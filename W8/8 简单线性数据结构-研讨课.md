# Git 是什么？GitHub 是什么？

| | Git | GitHub |
|:---|:---|:---|
| **是什么** | 本机上的**版本控制工具** | 托管 Git 仓库的**网站** |
| **类比** | 本地自动保存 + 完整历史 | 把项目放到云端，老师/组员可访问 |
| **文件** | 在项目文件夹生成 `.git/` | 网页上创建 Remote Repository |

**关系**：Git 管"怎么记录变更"；GitHub 管"仓库放哪、谁来看"。

W4 的 `report.md` 在 GitHub 上可直接预览 Markdown。本周只提交 **`README.md`** 和 **`.gitignore`**。

# Git 核心概念

```
工作区（你编辑的文件）
    │  git add
暂存区（staging，待打包的快照）
    │  git commit
本地仓库（.git/，完整历史）
    │  git push
GitHub 远程仓库（云端备份）
```

| 概念 | 含义 |
|:---|:---|
| **仓库 repository** | 被 Git 跟踪的项目文件夹 |
| **commit** | 一次有说明的快照（"保存点"） |
| **push** | 把本地 commit 上传到 GitHub |
| **clone** | 从 GitHub 复制一份到本机 |

# 环境准备：安装与配置

**一次性配置**（把名字和邮箱换成自己的）：

```bash

git config --global user.email "你的邮箱"
git config --global init.defaultBranch main
```

**检查**：

```bash

```

# .gitignore：哪些文件不要提交

```gitignore
# .gitignore 放在 w8_lab 根目录
__pycache__/
*.pyc
.vscode/
.DS_Store
```

```bash
git add .gitignore
git add .
git commit -m "添加 gitignore"
```

**原则**：只提交**源代码和 README**；不提交缓存、IDE 配置、含密码的文件。

# 任务：推送到 GitHub（约 16 分钟）

**步骤**：

1. 登录 [github.com](https://github.com) → **New repository**
2. 仓库名 `fip-w8-lab`；**不要**勾选「Add a README」（本地已有）
3. 创建后复制 HTTPS 地址，例如 `https://github.com/用户名/fip-w8-lab.git`

```bash
cd w8_lab
git remote add origin https://github.com/你的用户名/fip-w8-lab.git
git branch -M main
git push -u origin main
```

**验证**：刷新 GitHub 网页，应能看到 `README.md`。

# Git / GitHub 典型错误

| 典型错误 | 现象 | 修正 |
|:---|:---|:---|
| 未 `git add` 就 commit | `nothing to commit` | 先 `git add 文件` 或 `git add .` |
| 未配置 user.name / email | commit 被拒绝 | `git config --global user.name "..."` |
| `remote origin already exists` | 重复添加远程 | `git remote -v` 检查；或 `git remote set-url origin URL` |
| push 要登录失败 | 403 / 认证错误 | 使用 GitHub Personal Access Token 或 GitHub Desktop |
| 提交了 `__pycache__` | 仓库里一堆 .pyc | 写 `.gitignore` 并 `git rm -r --cached __pycache__` |
| commit 信息太 vague | 看不出改了什么 | 用 `W8 研讨：第一次提交` 这种说明 |
