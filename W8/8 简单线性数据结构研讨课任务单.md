## 第二节：Git 与 GitHub

每组一台笔记本。记录员操作，其他人看屏幕并核对命令。

### 1. 配置

```bash
git config --global user.name "你的姓名"
git config --global user.email "你的邮箱"
git config --global init.defaultBranch main
git --version
```

### 2. 第一次 commit

新建文件夹 `w8_lab`，里面只放 `README.md`：组号、成员姓名、日期。

```bash
cd w8_lab
git init
git status
git add README.md
git commit -m "W8 研讨：第一次提交"
git log --oneline
```

`.gitignore` 写上 `__pycache__/`、`*.pyc`，再 `git add .gitignore` 并再 commit 一次。

### 3. 推送到 GitHub

1. 新建仓库，名字 `fip-w8-lab`，不要勾选 Add a README
2. 复制 HTTPS 地址

```bash
git remote add origin https://github.com/你的用户名/fip-w8-lab.git
git branch -M main
git push -u origin main
```

刷新网页，能看到 `README.md` 即完成。记录员在仓库 Settings → Collaborators 里加上组员。
